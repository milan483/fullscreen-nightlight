# Architecture

## Scope
Temporarily inhibit KDE Night Light while an eligible fullscreen window exists. KWin retains control of temperature and scheduling. Inhibition is global across outputs; an output allowlist controls triggers, not color temperature per screen.

## Components
- `kwin-script/contents/code/main.js`: window eligibility, best-effort occlusion, event coalescing (100 ms), periodic refresh (5 s). Optional comma-separated KWin script configuration keys: Outputs and ExcludedApps.
- `helper/inhibitor.py`: session-bus service org.fullscreennightlight.Inhibitor, Refresh(boolean), sender checked against current org.kde.KWin owner. A 15 s lease bound to the authorizing unique KWin sender controls a dedicated D-Bus connection to the NightLight API. Typed unsigned cookies, 5 s failure backoff, connection closure on ambiguous transitions. KWin and NightLight must have the same unique owner, and the two connections must be on the same bus daemon.
- `install.py`: copies a fixed payload and generates D-Bus and systemd service files from XDG paths; no service activation or desktop configuration writes. Versioned ownership records, no-follow path traversal, a directory lock and a durable staged transaction support safe upgrades and recovery. See [installer safety](INSTALLER.md).

## Trust and failure boundaries
Only the current KWin bus owner can request refresh; same-user processes remain outside a strong security boundary. Never release another application's cookie. No network calls. The [KWin 6.8.3 implementation](https://github.com/KDE/kwin/blob/3e528155d822d41285a509d09751a88fa956267f/src/plugins/nightlight/nightlightdbusinterface.cpp) associates cookies with unique senders, ignores unknown sender/cookie pairs and removes a sender's inhibitors when that sender disappears. Closing the dedicated connection is the recovery mechanism for ambiguous calls, unknown cookies and owner changes; no global inhibited-property inference or configuration writes. The helper subscribes to KWin and NightLight name changes instead of polling owners on every active tick. KWin owner loss invalidates the lease; a new owner must send a fresh heartbeat. NightLight name loss invalidates the cookie even when KWin's owner remains the same; reacquire only while the lease is valid and both names match. Control-bus/name loss and unconfirmed connection cleanup are fatal, allowing the existing service activation/restart and heartbeat mechanism to start a fresh helper. A helper starts without a lease. Failures are retried no sooner than 5 s; one warning per failure streak and a recovery message avoid repetitive logs. Idle expiry checks retain the existing one-second timer, without continuous D-Bus polling.

The upstream implementation supports this ownership model, but actual KWin behavior requires native verification. A silently discarded cookie within an unchanged service instance is not detectable from the public aggregate inhibited property; no unsupported per-cookie query is assumed. Lease expiry is based on monotonic time and processed by the main loop; synchronous local bus operations, scheduling delays and suspend can affect wall-clock timing. Calls have a one-second reply timeout; connection setup/close do not have a separately enforced hard deadline. Same-user name impersonation when KWin is absent is outside the trust boundary. Native D-Bus/systemd activation, restart policy and login recovery are not certified by the mock tests.

## Known limitations
Borderless detection is conservative when maximizeMode is absent; occlusion is approximate. Native window API/timer behavior, lock screen, multi-monitor transitions, plugin reload, compositor restart and login persistence remain unverified. Installer recovery assumes a local filesystem with durable directory fsync, hardlinks and advisory locks; malicious same-user processes are outside its trust boundary. The integration harness launches a dedicated D-Bus daemon with a minimal configuration and no ambient service activation directories. It never connects to the desktop bus. Mock tests do not certify actual compositor behavior.
